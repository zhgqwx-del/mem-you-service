# 标准运费报价

## 目标与范围

由结算流程基于商品小计确定固定运费或免运费，并明确非法输入的错误语义。此次变更覆盖 Python 函数入口，范围见[当前规范](../../../specs/shipping/spec.md)。

| 改动 | 需求 | 目标行为 | 验收场景 |
| --- | --- | --- | --- |
| 新增门槛规则 | `REQ-SHIP-001` | 低于 9,900 分收取 800 分，达到门槛即免运费 | `AC-SHIP-001` 至 `AC-SHIP-003` |
| 新增输入验证 | `REQ-SHIP-002` | 仅接受非负内置整数，无效输入抛出 `ValueError` | `AC-SHIP-004` |
