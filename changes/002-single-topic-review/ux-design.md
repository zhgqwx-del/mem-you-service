# 单主题个人经验与规律回顾体验

## 适用范围

从现有 Agent 会话发起「复盘一下过去两周，我试过哪些办法避免出门漏带东西」。默认按可信时区内最近 14 个已结束的自然日回顾本人记录。使用同一会话的普通回复入口呈现，支持查看回答所用的可见证据。范围外的问题可继续由现有功能按各自能力处理。

## 流程和状态

| 用户动作或状态 | 用户可见结果 | 验收场景 |
| --- | --- | --- |
| 明确请求试点主题回顾 | 告知实际观察日期，列出找到的做法、结果和出处。重复或短暂选择带上场景 | AC-REVIEW-001、003、004 |
| 主体、主题、日期不明或超范围 | 请用户选一个有效范围。只有用户未指定日期且具备可信时区时才用默认窗口，并明示日期 | AC-REVIEW-001 |
| 仅有单次经历或部分证据 | 回顾已知项，指出缺的是发生日期、结果还是记录覆盖。可提供用户主动选择的扩大范围入口，最多 28 个已结束的本地自然日 | AC-REVIEW-001、005 |
| 同一次出门存在互相冲突的结果 | 说明已看到的两种记录及来源，标记结果待确认。该次出门只计一次 | AC-REVIEW-003 |
| 范围内无可用记录 | 「这段时间的可用记录里，没有找到出门准备和漏带结果的相关内容。」 | AC-REVIEW-005 |
| 覆盖未完成 | 「我目前只核到了部分记录，可以先回顾这些经历。整段时间的情况还无法判断。」 | AC-REVIEW-005 |
| 同一账号已有另一回顾在执行，或执行时间用尽 | 忙状态提示稍后再发起。超过新内容的交付时限时，仅提示本次未完成及重新回顾入口 | AC-REVIEW-005、006 |
| 当前版本或权限无法验证 | 「这次暂时无法核对可用记录，请稍后重新回顾。」 | AC-REVIEW-005、007 |
| 另发一次回顾请求 | 以本次范围的当前证据给出结果，可提及本次可见的新记录。原回答的文本不进入证据集 | AC-REVIEW-006 |
| 回看过期或已失效的回顾 | 只显示可证明的状态及重新回顾入口。过期提示「这次回顾已过期，可以重新回顾」，无需暗示来源被删除。已失效时隐藏受影响的旧正文。出处权限依现行取证协议 | AC-REVIEW-006、007 |
| 提到「这次说详细些」或确认新的长期偏好 | 当轮要求用于当前回复。用户明确设长期偏好时按原流程写入和回执 | AC-REVIEW-008 |

## 合成样例

> 11 月 9 日到 22 日，在我能核对的记录里，你有 4 次在前一晚按清单收包。两次明确记了带齐，一次还是漏了工牌，还有一次没记录结果。
>
> 还有一次明确记了没提前准备，出门后发现漏了钥匙。可比较的记录较少，目前只能回顾这些经历。

日期和事实链接来自[合成验收计划](test-plan.md)。例中的好坏结果按具体事件取证，涉及未知和覆盖的表达跟随证据状态。证据受限时不显示受限来源的数量和内容。窗口、呈现及用户确认的取舍随[需求草案](spec.md)一起评审。
