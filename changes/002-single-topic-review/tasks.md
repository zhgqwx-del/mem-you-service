# 单主题个人经验与规律回顾任务草案

## 实施方案

- 状态 设计基线已收尾。开发与执行验收待后续安排。
- 入口 在已有 Agent 会话中由可信宿主识别用户明确发起的本人单主题回顾，绑定会话、回顾范围和授权。沿用 full_lifecycle 来源和受控交付。
- 组件 由 MemoryService 对已摄取来源有界枚举，逐项记录判读，程序从已核验的事件生成计数、必要反例及交付限制。宿主核对结构化结果、处理待定动作阻断和发送队列。 [技术设计](design.md)
- 实施取舍 按[内部取证协议 v1](design.md#内部取证协议-v1)与[试点资源预算](spec.md#试点资源预算)起草验收，所有消费复用现有失效门禁。传输适配、能力发布标识及部署预算在实现评审确认。宿主能否控制回复重放和压缩副本是生产适用前置。
- 验收方式 先核对 AC-REVIEW 场景涉及的公开 Agent 入口，再建确定性来源、授权、响应缓冲和时钟夹具。用同一主模型评测有界归纳的新增收益。 [验收计划](test-plan.md)
- 确认记录 用户确认本切片按 14 日默认和 28 日上限设计，本轮范围为文档。具体部署资源线和真实效果待试点评审。 [决策及待验证项](change.md#决策及待试点验证项)

## 后续切片与关联场景

- [ ] `T-01` 核对主题可用的摄取内容、调用方与 Host 门禁，按已确认窗口和初始硬预算标注夹具。取得授权开发样本后校验窗口密度，冻结样本配额、分层门槛及货币费用和时延验收线。适用 AC-REVIEW-001 至 009。
- [ ] `T-02` 实现用户请求、范围确定、窗口内枚举及事件身份核对。适用 REQ-REVIEW-001、002、005，AC-REVIEW-001、002、005、008。
- [ ] `T-03` 实现候选提取、证据核验、反例与缺口输出，有界降级和拒用。适用 REQ-REVIEW-003，AC-REVIEW-003、004、005。
- [ ] `T-04` 接入同键重试、新准备、逐动作阻断及读屏障、宿主发送和消费者清理。适用 REQ-REVIEW-004、005，AC-REVIEW-006、007、008，并回归 04 中受影响的 G/C/A 项。
- [ ] `T-05` 在评测计划冻结后执行双组对照，记录实际覆盖、分层质量、效用和成本。同步已确认的合同分册、能力清单和验收编号。适用 REQ-REVIEW-006、AC-REVIEW-009。

当前仓库无独立 MemoryService 应用、依赖锁、启动与合同测试入口。文档检查与服务验收分别记录在[验收记录](verification.md)。
