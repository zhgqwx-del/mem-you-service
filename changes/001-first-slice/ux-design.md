# Memory D1 首个切片的调用方状态

本切片在公共 HTTP 验收中显式观察三类状态。产品侧继续按 [正式提交与记忆回执](../../docs/spec-v1/00-boundaries-and-invariants.md#22-recordservice的outbox与完成阶段)呈现结果。

| 状态 | 调用方可观察结果 | 验收 |
| --- | --- | --- |
| 产品已经保存，Memory 暂不可达 | 用户仍可按原产品回执看到已保存。导入方保留待投递事件。 | AC-MEM-005 |
| Memory 已接收，等待前序 | 导入方以原 operation 查询接收状态。需要本次证据的调用等待连续屏障。 | AC-MEM-003、AC-MEM-004 |
| Memory 已应用 | 导入方确认原 operation 及来源版本，授权验证者可精确查询当前结构化字段。 | AC-MEM-003、AC-MEM-006 |
| 连接丢失、冲突或权限不足 | 断线后沿原身份核对。冲突进入对账，权限不足按合同显示安全错误。 | AC-MEM-001、AC-MEM-004、AC-MEM-005 |

本段的交付界面为 HTTP 与产品夹具。实际产品 UI 和 Agent 的记忆反馈接入随各自阶段推进。
