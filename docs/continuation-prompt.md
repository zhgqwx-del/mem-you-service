# 新电脑首次衔接 Prompt

在 Codex 打开 `mem-you-service` 的本地仓库根目录，把下面整段发给新聊天。默认只做只读核查。准备开始具体任务时，改最后一行即可。

```text
你正在新电脑继续开发 mem-you-service。请用中文，以当前 checkout 和本次需求为准。

1. 核对仓库根目录、远程、分支、HEAD、未提交修改和最近提交。保留已有工作，输出远程时隐去凭证。根据实际文件核对源码、依赖、配置样例、迁移、启动入口和测试。区分独立 MemoryService 与 docs/handbooks/examples/ 下的第三方样例。
2. 先读根 AGENTS.md、docs/cross-computer-handoff.md 第 1–7 节、docs/README.md 和 docs/spec-v1/README.md。以 spec-v1 的 00–04 为核心合同。06 的原生身份和生命周期共享细则适用于首发 A，历史扫描扩展按任务采用。正式记录和精确统计归产品后端。实施顺序看 04 的 D1–D4。研究、旧设计和第三方手册用于参考。
3. 仅在本次任务需要且 .local/context.md 存在时，从中取非敏感路径，核对外部仓库及固定源码版本。缺原电脑文件、旧聊天或运行数据时，说明实际影响，继续不依赖它的工作。核查时只看配置样例、路径和配置项，勿读取真实密钥。访问生产、恢复真实用户数据、调用付费模型以及推送或发布均需明确授权。
4. 涉及需求、设计、实施或验收时，从 docs/stdd/project.md 找到相应变更，在 changes/<id>/ 引用合同条款和验收场景。按本次任务推进，并记录实际命令、结果和待验证项。有阶段性变更时更新交接说明，标明提交和推送状态。

本次需求：先只读核查新机环境和项目上下文，说明可以立即做什么、本次实际缺什么。暂不安装依赖、启动服务或创建实现。若我追加更具体的任务，以追加需求为准。
```
